# 목표
- 에이전트는 LLM을 이용하여 추론(Reason), 행동(Act)을 교차 반복하여 문제를 자율적으로 해결 -> 인공지능 패턴: ReAct
- 한번의 ReAct 호출을 넘어 결과를 검증 -> 재시도 -> 루프 구조 구성
- 제한을 두고 반복 수행 진행(임시 -> 비용/사긴 절감) -> 처리가 되지 않으면 Human in the loop를 같이 적용 가능
- 질문 -> 답변, 계획 -> 실행 -> 검증 -> 부족하다고 평가 -> 수정 계획 -> 실행 ... 으로 작동하는 Agent 구성
- 위처럼 Agent를 작동시키는 방식을 루프 엔지니어링이라 함
