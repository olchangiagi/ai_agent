# 목표
- 프롬프트 엔지니어링 적용
```
# Role(역할)

# Context(내용)

# Task(실제로 할일, 지시사항)

# Constraints(제약 사항)
```
- 필요시 퓨샷(셈플 제공) 적용
- 프롬프트 양식(폼, 형태)는 최적의 답을 얻기 위한 어플리케이션의 핵심 내용 관리

# 구조
/
L app/
    L prompts.py    : 프롬프트 구성, 퓨샷
L steps/
    L step3_prompt_engineering.py   : 프롬프트 엔지니어링 기술을 적용하여 LLM 질의

# 실행
```
python -m steps.step3_prompt_engineering

반복되는 문의에 지치는 CS팀을 위한 AI 고객상담 솔루션입니다.

자주 묻는 질문은 AI가 먼저 응대하고, 복잡한 상담만 상담원에게 연결됩니다.

응답 대기 시간을 줄이고, 팀은 더 중요한 고객 응대에 집중할 수 있습니다.

번거로운 설정 없이 기존 채널에 바로 연동됩니다.

지금 무료로 체험해보고 우리 팀에 맞는지 확인해보세요.

반복되는 문의는 AI가, 섬세한 상담은 사람이.
CS팀의 시간을 단순 응대가 아닌 고객 경험에 쓰세요.
자주 묻는 질문은 24시간 즉시 응답하고, 복잡한 문의는 자동으로 담당자에게 연결됩니다.
쌓인 상담 데이터는 그대로 서비스 개선의 인사이트가 됩니다.

지금 무료로 체험하고, 우리 팀에 맞는 상담 흐름을 직접 확인해보세요.
```
